# 故障演练脚本（模拟数据）

> 这是**演练用的模拟剧本**：注入故障、观察告警、走一遍预案。文中出现的"CPU 80%""错误率 50%""P99 3 秒"等数字均为演练注入目标，不是真实处置手册。真实排障请读 service_unavailable.md / slow_response.md 等正式文档——评测用它检验系统能否区分"演练脚本"与"真实处置"。

## 演练流程

1. 低峰期由平台注入：CPU 打到 80%、模拟错误率 50%；
2. 观察 5 分钟内告警是否触发（system-metrics 面板）；
3. 值班按预案执行摘流量/重启；
4. 恢复后记录演练报告：告警时延、MTTR、预案偏差项。
