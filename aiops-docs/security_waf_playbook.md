# WAF 安全防护处置手册

## 覆盖的攻击类型

- SQL注入：特征化拦截 + 参数化查询治本；
- XSS：输出转义 + CSP；
- CC 攻击：限流（IP/会话维度）+ 人机校验。

## 误报处置

业务请求被 WAF 拦截时，先确认是否为误报，再走白名单流程：

1. 定位规则 ID 与命中特征；
2. 白名单**按 URL + 规则粒度**添加，禁止整站放行；
3. 白名单变更需安全团队审批并记录有效期。

## 与其他组件的边界

- TLS 证书问题（CN/SAN/secret 配置）不在 WAF 范围，见 k8s_ingress_tls_guide.md；
- WAF 只拦入口流量，数据库备份安全见 mysql_backup_restore.md。
