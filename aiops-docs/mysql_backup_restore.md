# MySQL 备份与恢复手册

## 备份方案

- **全量**：xtrabackup 物理备份（锁表短、恢复快），生产默认方案；
- **增量**：binlog 归档，配合全量可恢复到任意时间点。

## 恢复流程（以 PITR 为例）

1. 最近一次 xtrabackup 全量恢复到临时实例；
2. 记录全量对应的 GTID 位点；
3. 用 `mysqlbinlog` 回放 binlog 至目标时刻，`--stop-gtid` 精确截断；
4. **校验**：恢复后核对关键表行数与业务抽样数据，GTID 集合连续无空洞方可切流。

## 原则

- 任何恢复操作先在临时实例完成校验，禁止直接对生产回放；
- 每次恢复演练留档，与 mock_incident_drill_script.md 的演练流程配合。
